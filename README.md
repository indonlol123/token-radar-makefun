Token launch radar ranking pre-token protocols by implied value. A market-based model (implied = TVL × category multiple × growth × maturity) ranks 198 protocols, with a sortable dashboard, watchlist filter, per-protocol farm plans, and a live-token calibration table.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
